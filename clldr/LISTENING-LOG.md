# CLLDR — listening evaluation template

Manual laboratory notes, not a patch format or final ZW saving convention. See [DISCOVERY-AUDITION.md](DISCOVERY-AUDITION.md) for test recipes and classification definitions. Nothing below asserts a listening result.

- History controlled by clean onset, or deliberately continuous:

## Session conclusion

- Distinct musical contribution, if demonstrated:
- Overlap with another parameter and how it was tested:
- Works across which notes, source pairings and interaction modes:
- Actual visual behaviour observed (not an inferred chaos/stability label):
- Dynamic differences retained; any level-matching limits:
- Candidate placement: main fascia / medium bank / detailed editing / removal candidate / undecided:
- Evidence needed before a design or deletion decision:

A clipping/stalling/aliasing observation is not automatically a poor musical result. A different waveform or nonzero numerical output is not automatically a useful musical result. Leave classification Untested if the evidence does not support a decision.
